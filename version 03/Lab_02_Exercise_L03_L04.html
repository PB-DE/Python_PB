Part 4: Practical Modeling: Runway Assignment & Crosswind Limits 25 Pts

When landing, an aircraft experiences a Crosswind Component (Vcross) and a Headwind Component (Vhead):

Vcross = Vwind × |\sin(θdiff)|,    Vhead = Vwind × \cos(θdiff)

Where:

  • Vwind = Wind speed (knots)
  • θdiff = Wind Direction - Runway Heading (in radians: math.radians(degrees))

Requirements:

Write a function check_landing_clearance(runway_heading, wind_dir, wind_speed, max_crosswind=15.0) that:

  1. Calculates Vcross and Vhead.
  2. Evaluates clearance:
    • If Vhead < 0, it is a tailwind; if tailwind exceeds 10.0 knots, landing is “REJECTED: Excessive Tailwind”.
    • If Vcross > maxcrosswind, landing is “REJECTED: Crosswind Limit Exceeded”.
    • Otherwise, landing is “CLEARED: Safe Landing Conditions”.
  3. Returns a tuple (clearance_status, crosswind, headwind).

Prompt the user to enter parameters interactively and print the flight operations dispatch report.

Example Run:

Enter wind direction (degrees): 130
