High-Performance Computing

Array Processing with NumPy

NumPy (Numerical Python) is the foundation of the scientific Python ecosystem, engineered for high-throughput mathematical array computing.

  • Python Lists: General-purpose containers storing pointers to separate heap objects with dynamic typing overhead.
  • NumPy Arrays (ndarray): Store homogeneous, densely packed data in contiguous C-level memory blocks.
  • Vectorization: Mathematical operations execute natively in C without Python loop overhead.
  • Standard convention: import numpy as np

Memory Homogeneity

Array Data Types: The dtype Attribute

Unlike Python lists which allow mixed types, every element in a NumPy array must share the identical scalar data type.

  • Type Inference: NumPy determines the most efficient native C type automatically upon construction.
  • Integers default to 64-bit signed integers (int64).
  • Floats default to 64-bit IEEE floating-point numbers (float64).
  • Mixed integer and float arrays are coerced up to float64.

Hardware Architecture

Memory Layout: Python List vs. NumPy ndarray

Why is NumPy exponentially faster for numerical workloads than standard Python lists?

  • Python List: Array of 64-bit memory pointers referencing separate boxed PyObject structures scattered on the heap. Poor CPU cache locality.
  • NumPy ndarray: Contiguous buffer of unboxed raw binary values with a small metadata header.
  • Enables direct SIMD hardware vectorization and cache pre-fetching.

NumPy provides multiple mechanisms for looping over multidimensional array structures.

  • Flattened Iteration: The .flat attribute provides a 1-D iterator over all elements in memory order without reshaping or copying.

Directional Reductions

Axis-Based Reductions: Row Sums vs. Column Sums

The axis parameter controls the direction along which an aggregation collapses dimensions.

  • axis=0 (Vertical): Collapses across rows → Computes sum of each column.
  • axis=1 (Horizontal): Collapses across columns → Computes sum of each row.
  • Rule of thumb: The specified axis is the dimension that gets eliminated during the operation.
python — axis_reductions.pyDirectional Sums

Output

Modern String Formatting: The Power of f-strings

Python introduced formatted string literals (f-strings) in Python 3.6, replacing legacy formatting methods.

  • Legacy % Operator: C-style '%0.2f' % 3.14156 (error-prone with complex types).
  • Legacy str.format(): '{:0.2f}'.format(3.14156) (verbose syntax).
  • Modern f-strings: Prefix string with f'...' and embed expressions directly in curly braces: f'{val:specifier}'.
  • Faster, concise, and evaluated directly in Python bytecode.

Pipeline Architecture

Text Processing Pipeline: Split & Join Operations

Parsing, filtering, and reassembling structured strings follows a clean, repeatable two-phase pipeline.

  • Phase 1 — Tokenize: .split(';') consumes the raw input string and produces a list of clean tokens.
  • Phase 2 — Transform: Filter, capitalize, or reorder elements within standard Python list workflows.
  • Phase 3 — Reassemble: ' '.join(tokens) glues items into the desired target format with custom delimiters.

Quantifiers & Anchors

Regex Validation: Postal Codes & Quantifiers

Quantifiers specify the exact number of times a preceding character or group may repeat.

  • \d: Matches any decimal digit character ([0-9]).
  • {5}: Exact quantifier: matches exactly 5 times.
  • r'^\d{5}$': Enforces exactly 5 digits from string start (^) to end ($).
  • Matches '90210' and '10031'; rejects '9486' (too short) or letters.

Custom Sets

Character Classes & Twitter Handle Validation

Character classes enclosed in square brackets [...] match any single character belonging to a custom set.

  • [A-Za-z0-9_]: Matches any alphanumeric character or underscore (equivalent to \w).
  • {3,}: Range quantifier: matches 3 or more occurrences.
  • Pattern r'^@[A-Za-z0-9_]{3,}$': Validates handles starting with @ followed by at least 3 valid identifier characters.
  • Rejects invalid prefix characters (e.g. #) or handles that are too short (@A).
